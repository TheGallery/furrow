# Security

Furrow is a static browser game. It has no server, no accounts and no user data; your progress stays in your own browser's local storage.

If you find a security problem, please report it privately through the repository's **Security** tab (**Report a vulnerability**) rather than in a public issue. Only the latest version on `main`, which is what https://thegallery.github.io/furrow/ serves, is supported.
